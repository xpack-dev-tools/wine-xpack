The [xPack WineHQ](https://xpack-dev-tools.github.io/wine-xpack/)
is a standalone binary distribution of
[WineHQ](https://www.winehq.org).

There are binaries for **x64 GNU/Linux**.

## Download

The binary files are available from <a href={frontMatter.download_url}>GitHub Releases</a>.

## Install

The easiest way to install this specific version, is by using **xpm**:

<CodeBlock language="console"> {
`xpm install @xpack-dev-tools/wine@${frontMatter.version}.${frontMatter.npm_subversion} -verbose
`} </CodeBlock>

Comprehensive instructions for installing **xPack WineHQ** on different platforms
can be found in the [Install Guide](/docs/install/).

## Compliance

The **xPack WineHQ** is based on the official
[WineHQ](https://www.winehq.org), with no changes.

The current version is based on:

- WineHQ release
[{frontMatter.wine_version}](https://dl.winehq.org/wine/source/{frontMatter.wine_version}/) from {frontMatter.wine_release_date}.

## Build

The binaries for all supported platforms
(GNU/Linux) were built using the
[xPack Build Box (XBB)](https://xpack.github.io/xbb/), a set
of build environments based on slightly older distributions, that should be
compatible with most recent systems.

For the prerequisites and more details on the build procedure, please see the
[Maintainer Info](/docs/maintainer/) page.

## CI tests
